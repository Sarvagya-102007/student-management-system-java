# STUDENT MANAGEMENT SYSTEM

A Java-based command-line application designed to manage and organize student information through a simple and interactive terminal interface.

## Features

- Add student information
- View all students
- Search students
- Update student information
- Delete student records
- Manage academic performance
- Calculate grades based on CGPA
- Manage attendance
- Calculate attendance percentage
- Display attendance status
- Calculate average CGPA
- Calculate average attendance
- Generate student reports in CSV format
- Store student data locally
- Input validation and exception handling

## Student Information

The system stores:

- Student ID
- Student Name
- Course
- Semester
- Email
- Phone Number
- CGPA
- Total Classes
- Attended Classes

The system automatically calculates:

- Grade
- Attendance Percentage
- Attendance Status

## Technologies Used

- Java
- Core Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
- File Handling
- Java Serialization
- CSV File Handling
